# 📊 CodeAlpha – Power BI Data Analytics Projects

## About the Projects

As part of my CodeAlpha Data Analytics Internship, I worked on two Power BI projects to explore datasets and create interactive dashboards.

These projects helped me understand how data visualization can be used to analyze information and present meaningful insights.

## Projects

### 1. HR Analytics Dashboard
This dashboard focuses on employee and recruitment analysis.

**Key Insights:**
- Employee Attrition Analysis
- Department-wise Employee Distribution
- Average Salary Analysis
- Job Satisfaction
- Hiring Rate by Department
- Average Days to Hire

### 2. Student & Resource Performance Dashboard
This dashboard focuses on student performance and college resource utilization.

**Key Insights:**
- Student Pass and Fail Analysis
- Department-wise Student Distribution
- Average Marks
- Average Attendance
- Resource Allocation by Type

## Tools & Technologies
- Microsoft Power BI
- Power Query
- DAX
- Microsoft Excel
